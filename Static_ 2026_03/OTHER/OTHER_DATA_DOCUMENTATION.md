3. **面积为空的 `Total*`**：`hsefa2025e.xlsx` 最后列叫 `Total*`（带星号），含义是"包含面积未知项"，**与 `4 + 1` 个面积分箱汇总值不等**，需要额外花 `Total* - Σ(分箱)` 去还原"未分类"。
4. **HDB 两种 Total**：`hsetod2025e.xlsx` 同时存在 `Total`（全国所有住宅）与 `Total HDB^`（仅 HDB），后者含 `^` 上标——pandas 默认按字符串读会丢标点，请保留原样以便后续审计。
5. **`respopagesex2025e.xlsx` 工作表名是字面 `2025`**，不是 `Sheet1`：
   ```python
   pd.read_excel(path, sheet_name="2025", header=2)
   ```
6. **尾部几万行的中文 `Total`/`Singapore`**：3 个 respopagesex 文件尾部多行可能在 `Notes` / `Definitions` 区间，需要在清洗时以 `"总"`、`"Table"`、`"Note"`、`"Source"` 关键词截断。
7. **单次行数巨大**：`respopagesex2025e.xlsx` 单页 10 万行，建议用 `dtype={...}` + `usecols=` 读子集，避免一次性 `read_excel` 占满内存。

### 12.9 读取陷阱与推荐做法

1. **列头深度不固定（最常见错误）**：同一文件内 d ∈ {1, 2, 3}。不要用固定 `skiprows`。
   ```python
   import openpyxl
   wb = openpyxl.load_workbook(path, read_only=True, data_only=True)
   rows = list(wb[sheet].iter_rows(values_only=True))
   # 首行数据 = 第一个「第 2 列为数值」的行；末行数据 = 最后一个这样的行
   idx = [i for i, r in enumerate(rows) if len(r) > 1 and isinstance(r[1], (int, float))]
   first, last = idx[0], idx[-1]          # 列头 = rows[9:first]，数据 = rows[first:last+1]
   ```
2. **行主键带缩进**：Subzone 行以 **2 个空格**开头，PA 合计行在 (2) 中写作 `<PA> - Total`。分级前先判断 `s.startswith('  ')`，再 `s.strip()`。
3. **不换行空格 `\xa0`**：(5) 的 T3 / T12 / T13 等表主键含 `\xa0`，匹配前统一 `.replace('\xa0', ' ')`。
4. **尾块必须以"最后一行为数值"截断**：`Definitions and Footnotes:` / `Notation:` / `Related Information:` / `Generated by:` 之后全是文本，不能当成数据行。
5. **T10（工作地行程时间）只有 47 行**，其余 (3) 的 PA 表均为 48 行（少 `Works from Home`）。跨表合并请用 **PA 名做 key**，不要按行号对齐。
6. **`Works from Home` 受疫情影响**：(3) 中该项为 2020 年 Census 采集，用于 2026 年建模时需下调权重或做敏感性分析。
7. **(4) 与 (3) 的 PA 覆盖不同**：居住侧 30 个（+`Others`）、工作侧 44 个（+3 特殊类）。做 OD 时居住端与工作端的 PA 全集不一致，需取交集并单独处理 `Others` / `Other Planning Areas or Outside Singapore`。
8. **`Others1/` / `Others2/` / `Total1/` 带脚注上标**：pandas 读入后保留字面量，便于审计；求和时不要把它和具名分箱混为一谈。
9. **年龄组分箱在不同文件间不一致**：居住地 20 档（0-4 起）、工作地 11 档（Below 25 起）、学生 4 档、就业者 4 档。聚合到统一分箱后再跨表计算。
10. **`Data last updated` 不等于调查年份**：(4)/(3) 写着 18/08/2026，但数据是 Census 2020。判断年份只看表题括号。
