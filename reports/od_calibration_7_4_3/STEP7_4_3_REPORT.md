- `expansion_factor` = `T_ij/N_ij`（每 agent 代表的真实车次）；**Σ EF = 真实 car OD 总量**；

  **ΣodTrips 不是需求量**（它随 agent 数而非随「需求」变化）；
- **两者都不被 MATSim 消费** → 单独缩放它们是纯算术；**唯一物理需求杠杆 = 被仿真的车辆数（agent 数）**。

## 5. 判读与下一步

- **总体量级（08-09）**：D 系列 `Sim/Obs(all)` 跨 f 极差 **0.1530**；各档 = f=1.00→0.7070、f=1.10→0.7095、f=1.20→0.8601、f=1.25→0.7599 → **非单调**（峰@f=1.20）；最强档仍仅 **0.8601 < 1**（距 1 差 **0.1399**） → 加车**不能单独**补齐量级缺口。
- **结构（CATA/SLIP）**：跨 f 极差 **0.1738**（= λ 极差 0.0146 的 **12×**、= capacity 极差 0.2371 的 **73%**）；取值 f=1.00→1.0642、f=1.10→0.9031、f=1.20→0.9363、f=1.25→0.8904；**穿越 1**（CATA↔SLIP 相对高低反转）；**需求弹性（f 首→尾）**：SLIP ×**1.249** vs CATA ×**1.045** → SLIP 对需求更敏感，加车把结构**推向 SLIP** → 结构**不中性（显著移动）**。
- **阻尼解读（A − D）**：`A − D` = 算术参照 − 物理加车，**同时**包含「拥堵饱和」与「断面重分配」两种效应（算术参照冻结了 D01 的空间形态），故**不能**单独解释为拥堵；本步各档 = f=1.00→+0.0000、f=1.10→+0.0682、f=1.20→-0.0116、f=1.25→+0.1239（**非单调**，f=1.20 时为负 → 物理在该档甚至略高于等比外推）。
- **判据**：(a) 若 D 系列随 f 上升且接近 A 系列 → 网络未饱和，量级缺口主要是**需求总量**问题；(b) 若 D 系列明显低于 A 系列 → 存在**拥堵阻尼**，加车被饱和吸收；(c) 若仅总量改善而 `CATA/SLIP` 恶化 → 出现「总量对、空间错」，须回到 OD 空间结构 / λ。
- **λ 仍不冻结**；**不自行选定 f_demand**；下一步由用户依据本表判定。
