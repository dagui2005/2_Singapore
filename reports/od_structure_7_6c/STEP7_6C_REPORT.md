## 5. 判决与下一步

**判决 = `OD_STRUCTURE_PARTIAL`。**

**结构可信的三条（S5 / S6 / S7 通过）**：
1. **OD 的形状与普查一致** —— Table 118 物理格中位残差 0.0026（P95 0.0095）；
2. **无异常吸收区** —— 0 个 `|z|>5`；
3. **路由可信** —— detour 1.068–1.111，且 plan 口径与 linkstats 口径**独立互证**；质量守恒到浮点精度。

**必须直视的一条（S4 不通过）**：
- `0.8590` 的缺口**不是均匀的**：**东部 −32% / 东北部 +35%**、**radial_in −29%（正流 −16%）vs radial_out +14%**、**R5 外缘进中心 13/13 断面零仿真流**、沿海走廊 PA（HOUGANG / TUAS / KALLANG / PIONEER）系统性低估、中心商业 PA（ORCHARD / OUTRAM）系统性高估。
- 剔除 54 个零流断面（占 8.14% 观测）后全局升到 **0.9351**，但**区域偏差仅从 0.348 降到 0.333** ⇒ **结构性成分真实存在**。

**⇒ 结论**：OD **形状大体可信、但存在明确的定向空间结构偏差**，因此 **`0.8590` 不能当作一个"干净的规模因子"**；在补掉结构项之前直接做 demand-scale 扫描，会把**空间结构缺口的修正**误读成**需求规模响应**。

**下一步（对应决策树，须用户裁定）**：
- **(i)** 视结构"基本合理" → 进 **7.6F-1**（在冻结 R01 底座补跑 f=1.10/1.20/1.25，~4.25 h）建立稳定 demand-response curve；
