## 2. 方法

### 2.1 对向边池 `E_opp(s)`（**不要求有流**）

```
E_opp(s) = { e : ‖mid_e − mid_s‖ ≤ R=100 m
               ∧ highway(e) ∈ MAJOR = {motorway, motorway_link, trunk, trunk_link}
               ∧ circ_diff(bear_e, (bear_s + 180°) mod 360) < 30°
               ∧ e ∉ matched(s) }
```

**与 `7.9I-B(b)` 的唯一差别 = 去掉 `flow > 0`**。理由：`B(b)` 问「流量去了哪」（必须是有流对象）；
O1 问「**对象对应关系**」，必须允许「对向对象存在但无流」，否则无法区分
「没有对向对象」与「有对向对象但没流量」。⇒ **刻意的口径扩展，不是放松**。

### 2.2 对向有向链分量与代表值

在 `E_opp(s)` 诱导子图上取弱连通分量 `C`：

| 条件 | `rep(C)` |
|---|---|
| `C` 为**有向路径**（`|E| = |V|−1`，`max(outdeg) ≤ 1`、`max(indeg) ≤ 1`，且**恰有 1 个 `indeg=0` 起点、恰有 1 个 `outdeg=0` 终点**） | `median_{e∈C} flow_e` |
| 否则（**无向**路径但**折返** / 分支 / 多起点终点） | `Σ_{e∈C} flow_e` |

> **★为何不用「链内每步方位一致」**：`E_opp` 内每条边**已按方位筛过**
> ⇒ 该条件**恒真** ⇒ 是**命中 100% 的退化判据**（违反 `readme §4` 纪律，且本步已在运行前识破）。
> 有区分度的是**拓扑方向性**：一组方位都对的边仍可能在拓扑上**折返**（`A→B→C` 与 `C→B→A` 混装）
> ⇒ 不是同一股车流 ⇒ 只能 `sum`。实测 **57 个分量：`directed_path` 46 / `sum` 11** ⇒ 非退化。

`sim_pair(s) = SCALE × Σ_C rep(C)`；`r_pair(s) = sim_pair(s) / obs_s`。**链内不重复计数、跨链可加**（同 A1）。

### 2.3 对层分类

| 类 | 判据 | 含义 |
|---|---|---|
| **`Q0_TWIN_PAIR`** | `∃ e ∈ E_opp(s)` 使 `(t_e, f_e)` 存在（同节点对反向孪生） | **双向 way** 建模 |
| **`Q1_SEPARATE_CARRIAGEWAY`** | `E_opp(s) ≠ ∅` 且无孪生 | 对向车行道为**独立节点串** |
| **`Q2_NO_OPPOSITE_OBJECT`** | `E_opp(s) = ∅` | 邻近**没有**对向对象 |

### 2.4 候选对象选取三规则（后验 ①）

按 `readme §4`「**候选对象选取 > 统计量**」与「**多边映射必报计数基数 K**」：
R-sum = `Σ_C rep(C)`（预注册）／R-max = `max_C rep(C)`（单一最强对向链）／R-med = `median_C rep(C)`；
计数基数 `K_pair = n_comp` **必须同报**。

### 2.5 对向标签对照（后验 ②，★决定性）

对每个 `B2` 断面 `s`，在 LTA 侧找**方位相差 ~180°、几何邻近**的断面 `s'`
（**同一物理段的另一方向**；搜索 `R ∈ {100, 200, 300} m`，由近到远取首个命中）。
读 `s'` 的**冻结 canonical 指标**（`section_scale_v10.csv` 的 `sim_median_xS` / `ratio_median`）：

| 类 | 判据 | 归因 |
|---|---|---|
| **`L1_OPP_LOADED_OK`** | `s'` 的 `ratio_median ∈ [0.5, 2]` | **同一物理段两侧：一侧正常、一侧全零** ⇒ **对象层面** |
| `L2_OPP_ALSO_LOW` | `s'` 的 `ratio_median < 0.5` | 两侧都低 ⇒ 回到**需求 / 路径** |
| `L3_NO_LTA_OPP` | 300 m 内无方位相反且邻近的 LTA 断面 | 再分 `L3a`（MATSim 侧有 `E_opp`，属 **LTA 覆盖不足**）/ `L3b`（**两侧均无对向**） |

### 4.5 暴露面披露（不得省略）

1. **半径**：对向断面定位半径分布从 **26.4 m 到 292.9 m**；严格 `R ≤ 100 m` 时 `L1` 仅 **10 节 / 30.77%**，
   放宽到 300 m 才到 **18 节 / 51.86%**。⇒ **`L1` 的 51.86% 依赖 300 m 搜索半径**，
   ⛔ 不得当作无暴露面的数字；**保守读法是 30.77%**。
2. **`E_opp` 是「几何 + 拓扑」构造，不是「真值对应表」**：它只回答「邻近存在哪种形式的对向对象」，
   ⛔ **不得**读作「LTA 的这个断面就是 MATSim 的那条链」——那需要 LTA detector 元数据，本步不具备。
3. `r_pair ∈ [0.5, 2]` 仅说明**量级相容**，⛔ ≠ 「对层映射正确」。
4. `L2_OPP_ALSO_LOW` 的 15 节 / 40.26% 是**真实剩余缺口**，本步**未**解释。
