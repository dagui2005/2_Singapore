## 2. 方法（口径全部冻结）

### 2.1 三个「对象」定义（★本步唯一关键区分）

| 对象 | 定义 | 用途 |
|---|---|---|
| **本侧对象** | **交叉表 primary matched 边**（`is_primary_candidate=True`；`n_match` / `n_match_flow`） | 判「本侧是否建了 / 是否加载」 |
| **对向对象** | `R_MS=100 m` 内、`highway ∈ MAJOR`、`circ_diff(bear_e, bear_s+180°) < 30°` 的有向边 | 判「对向是否建了 / 是否加载」 |
| **邻近同向对象（几何池）** | `R_MS=100 m` 内、方位同向的 MAJOR 边 | ⛔ **仅作披露 / 双胞胎搜索**，**不作**「本侧对象」 |

> **★为何严格区分**：首跑把「几何同向池」当「本侧对象」，FAIL 3 项 —— 100 m 内会纳入
> **邻近其它道路 / 匝道**的同向有流边（与 LTA 断面无关）。见 §5 缺陷登记 **D1 / D2**。

### 2.2 OSM 侧（②）

- 源：`Singapore_OD_MATSim_FinalData/07_RoadNetwork/osm-lines_expanded.shp`（EPSG:4326 → **EPSG:3414**）
- 字段：`osm_id / highway / oneway / name / ref`；筛 `MAJOR = {motorway, motorway_link, trunk, trunk_link}`
- 方位：取**离断面中点最近那一段**的方位（⛔ 不是整条 way 的起终点方位，避免长 way 失真）
- 分组：`circ_diff < 30°` → 同向；`|circ_diff−180| < 30°` → 对向

### 2.3 MATSim 侧（①）

- `R_MS = 100 m`；有向链 = 同向/对向边集诱导子图的**弱连通分量**数（复用 O1 的 `weak_components`）
- 加载 = 链内任一边 `HRS8-9avg > 0`

### 2.4 死管诊断（本步新增，回答「为什么零流」）

对每条 matched 边，沿 **入度=1** 的反向链上溯至端点（`max_steps = 2000`），取端点节点

```
head_inflow(e) = Σ_{j ∈ in-edges(endpoint)} flow_j          （端点的全部入边流量之和）
head_inflow_max(s) = max_{e∈matched(s)} head_inflow(e)
```

| `iso_class` | 判据 | 含义 |
|---|---|---|
| `ISO_TWIN_EXISTS` | `R_TWIN=300 m` 内存在**同向、有流、非 matched** 的 MAJOR 边 | 有**平行同向对象**接住流量 |
| `ISO_DEAD_TUBE` | 否则，且 `head_inflow_max ≤ 0` | **结构性无接入**：上溯终点节点无任何有流入边 |
| `ISO_BYPASS_NO_TWIN` | 否则（上游有接入但无平行对象） | 上游有车但未进入本链 |

### 2.5 `U_UNIT_MISMATCH`（③，口径与 A2 严格一致）

```
vc_max(s) = obs_8_9(s) / max_{e∈matched(s)} CAPACITY(e)        （CAPACITY 取 linkstats 原始列）
vc_max > 1.0  ⇒  U_UNIT_MISMATCH（拿容量最大的匹配边也装不下观测 ⇒ 观测单元 ≠ 仿真单元）
```

2. 核对该节点在 **OSM** 里是否有连接 way（`motorway_link` / `trunk_link`）；
3. 若有 ⇒ **转换丢边**（`build_impedance` 的 `(u,v)` 去重 / 0.1 m 网格合并导致）；若无 ⇒ 本侧车行道在该段**本就无接入口**（可能是 OSM 数据缺失或管制）；
4. 对 `ISO_TWIN_EXISTS` 的 18 节（41.15%）：核验「替代对象」是否与 LTA 断面**同一物理车行道**（⛔ 不得只凭 35 m 邻近就下结论）。

⛔ 仍**零仿真**；**不触碰** v1.0 动力学参数；O2（`SIGNAL_MECHANISM_ABSENT`）/ `trafficDynamics` / `speedFactor` 须用户**显式裁定解除底线**后方可进入。
