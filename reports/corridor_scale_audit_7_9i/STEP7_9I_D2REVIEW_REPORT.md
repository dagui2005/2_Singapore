## 2. 方法

### 2.1 两个并列版本（唯一自由度 = 候选域）

| 版本 | 候选域 | 其余 |
|---|---|---|
| **R0**（基准） | `head` 经**零流边**反向可达（`max_active = 0`） | 选边 / 分类 = **D-path 原口径** |
| **R1**（实验） | 反向游走**允许跨越至多 1 条活边**（`max_active = 1`） | **完全不动** |

形式定义：`C_in^Rk = { e : flow(e) > 0 ∧ dom_k(to(e)) ≥ 1 }`，`dom_k` = 反向游走经过活边数 ≤ k 的最少跳数。

> ★为什么「跨 1 条活边」是**唯一**自洽的放宽：`head_in_flow == 0`（D-path `G-DP-4` 已证）⇒ 本链上游**不存在**零流路径之外的入口；跨 0 条即 R0，跨 ≥2 条等价于把「上游已到达」当假设。

**⛔ 五个不动**（用户指定）：`obs` / `SCALE` / `capacity` / **链定义** / `D1/D3/D4` 判据
⇒ **R1 只产出「同向候选检索」字段，不改变任何一节的 `final_class`**（`G-D2R-3` 实证）。

### 2.2 同向候选的**双口径**（承接「拓扑≠欧氏 必同报」纪律）

| 口径 | 规则 | 用途 |
|---|---|---|
| **hop 序**（主，用户指定字段） | 同向子集内 `argmin(hop, −flow, id)` | `same_dir_first_*` |
| **欧氏序**（诊断） | 同向子集内「到 `head` 欧氏距离最小」 | `same_dir_euc_*`，披露零流团惰性遍历伪影 |

实测两口径仅在 **9/14** 节一致 ⇒ **5 节必须同报**（`diagnostics.topo_vs_euc_same_dir`）。

### 2.3 ★三条防退化轴（**核心**：预期结果 = `F_ADQ 0/14` = 判据命中 100%）

按本项目已固化纪律（`readme §4`「**冻结判据命中 100% = 判据缺陷**」），0/14 本身是**判据缺陷信号**，

## 5. 判读

### 5.1 对正式问题的回答

> **是否因为当前候选域过窄，把「同向供流对象」人为排除掉了？**

**答：否。** 三条独立口径一致：

1. **对象存在性**：R0 冻结域**自身**已含同向活跃候选（14/14 节，2–37 个）⇒ 域从未把它们排除掉。
2. **量级合理性**：R0 与 R1 两个口径下，同向候选的承载倍率**上界**均 **< 0.50**（最高 0.452）⇒ 域内**
   根本没有**量级合理的同向供流对象。
3. **几何**：同向活跃对象到本链的最小距离下界 **407.9 m**，且**无一节**落在 60 m 内。

⇒ 结论**偏向用户预设的第一支**：
> **「本方向交通没有沿该 MATSim 车行道进入，而是在更上游发生路径分配差异。」**

且该结论**不是**「零流链内部存在路径/连接断点」那一支（后者要求「同向合理供流对象**大量存在**」，实测 `0/14`）。

### 5.2 与既有结论的一致性

| 既有结论 | 本刀关系 |
|---|---|
| **`D1 = 0` 是结构性退化**（D 类定义排除同向紧邻活流） | ✅ **未重解释**；本刀独立证实：R1 同向候选中**无一节**落在链 60 m 内 |
| **`12/14` 节链头 50 m 内同向对象全零流** | ✅ **一致**：本刀进一步给出「最近的同向**活跃**对象在 ≥407.9 m」 |
| **「改道离开被观测边」而非「车没跑」** | ✅ **加强**：同向供流对象在本方向**根本不存在量级合理者** ⇒ 与「本方向未进入该车行道」自洽 |
