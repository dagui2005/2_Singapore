## 1. 正式问题（用户 2026-09-30 裁定）

> **是否因为当前候选域过窄，把「同向供流对象」人为排除掉了？**

⛔ **本刀不是**「D2 是不是对向车在承载」的复核（该问法已被 D-path 判定为不可解释）。
✅ **本刀是**对 `C_in`（候选对象域）的**敏感性实验**：只动候选域，看能否**找回**同向供流对象。

**★关键判据（用户指定）**：不问「D2 变成多少」，只问
> **原 D2 六节中，有多少断面在放宽候选域后能够找到「同向、量级合理」的供流对象？**

「量级合理」**沿用已冻结阈值** `carry_scaled ≥ CARRY_MIN (0.50)`，⛔ 不新造阈值。

**结果落成**：
```text
D2 → same-direction candidate
├─ F_ADQ   （carry_scaled ≥ 0.50）
└─ F_LOW / none
```

**★保留既有结论（不重解释）**：
1. **`D1 = 0` 不重新解释**（结构性退化：D 类定义即排除「链头 50 m 内同向活流」）。
2. **`12/14` 节链头 50 m 内存在同向对象，但全部零流** ⇒ 本刀**不再**用「有没有同向对象」找答案；
   要追的是「**同向对象何时从 `zero-flow` 转为 `active`，且与实际承载链隔几层拓扑**」。
3. **`F_LOW`（D-path 报告 9 节 / 71.02% Σobs）暂不与 D2 混解**（缺 LTA detector / 设施层语义，
   继续推「需求不足」会触碰尺度纪律）⇒ 本刀只做 D2 复核。

## 2. 口径（运行前冻结，⛔ 不得改）

### 2.1 两个并列版本（唯一自由度 = 候选域）

| 版本 | 定义 | 作用 |
|---|---|---|
| **R0** | **当前冻结口径**：候选域 = `head` 经**零流边**反向可达（`max_active = 0`）；选边 = `argmin(hop, −flow, id)`；分类 D1–D5 完全不动 | **基准**（须与 D-path 卡片逐节一致） |
| **R1** | **仅**放宽候选域：反向游走**允许跨越至多 `MAX_ACTIVE = 1` 条活边**（其余全部不动） | **实验组** |

**R1 形式定义**：
`dom₁(n)` = 从 `head` 反向游走、**经过的活边数 ≤ 1** 时的最少跳数；
`C_in^R1 = { e : flow(e) > 0 ∧ dom₁(to(e)) ≥ 1 }`，`C_in^R0 = { e : flow(e) > 0 ∧ dom₀(to(e)) ≥ 1 }`。

> ★为什么「跨 1 条活边」是**唯一**自洽的放宽：`head_in_flow == 0`（D-path `G-DP-4` 已证）⇒ 本链上游**不存在**零流路径之外的入口；
> 若允许跨 **0** 条活边即为 R0，若允许跨 ≥2 条则等价于把「上游已到达」当假设，与 `head_in_flow == 0` 矛盾。

**⛔ 五个不动**（用户指定）：① `obs` ② `SCALE` ③ `capacity` ④ 链定义 ⑤ `D1/D3/D4` 判据。
⇒ **R1 只产出「同向候选检索」字段，不改变任何一节的 `final_class`。**

### 2.3 同向候选的**双口径**（承接「拓扑≠欧氏 必同报」纪律）

| 口径 | 选边规则 | 用途 |
|---|---|---|
| **hop 序**（主） | 在**同向**子集内 `argmin(hop, −flow, id)`（与 R0 选择规则同族） | 产出 `same_dir_first_*` |
| **欧氏序**（诊断） | 在**同向**子集内取「到 `head` 欧氏距离最小」 | 产出 `same_dir_euc_*`，披露零流团惰性遍历伪影 |

### 2.4 逐断面字段（★用户指定 5 项 + 必要诊断）

**★用户指定（必填）**：

| 字段 | 定义 |
|---|---|
| `same_dir_candidate_found` | `C_in^R1` 内是否存在**同向**活跃边（`circ_diff(bear_e, section_bear) ≤ DIR_OK`） |
| `same_dir_first_hop` | 该同向候选的 `dom₁` 跳数（无 ⇒ `-1`） |
| `same_dir_first_dist` | **候选边中点 → 链头节点 `head`** 的欧氏距离（m）（无 ⇒ `NaN`） |
| `same_dir_flow` | 该同向候选的 `flow`（veh/h） |
| `carry_scaled` | `same_dir_flow × SCALE / obs_8_9` |

**诊断（强制同报）**：`same_dir_class`（`F_ADQ`/`F_LOW`/`F_NONE`）、`same_dir_carry_max`（同向候选**全子集**的 `carry_scaled` 上界）、`same_dir_fl_max`、`same_dir_n`、`same_dir_d_min`（同向候选到**链**的最小欧氏距离）、`same_dir_euc_dist/hop/flow`、`same_dir_d_own_first`、以及 R0 侧 `r0_class` / `r0_e_near_id` / `r0_carry_scaled` / `r0_dbear`、域规模 `dom0_n` / `dom1_n` / `n_c0` / `n_c1`。

> ★`same_dir_carry_max` 是本刀**最关键的下界轴**：它是「同向候选里最强的那个」能提供的承载倍率上界。
> 若该值在 14 节上**全部 < 0.50**，则「找不到同向量级合理供流对象」不是「选择规则太挑」造成的，而是**域内根本不存在**。

### 2.5 ★判据非退化设计（防「命中 100% = 判据缺陷」）

**本刀预期结果 = `F_ADQ 0/14`（即 `F_LOW/none` 命中 100%）** ⇒ 按本项目已固化纪律
（`readme §4`「**冻结判据命中 100% = 判据缺陷**」），**必须在预注册阶段就并列细化轴与反证扰动**，否则该结论不可用。

| 轴 | 内容 | 作用 |
|---|---|---|
| **A1（下界轴）** | `same_dir_carry_max` 连续值 + 分位 | 把二值「命中/未命中」换成**连续上界**，0/14 不再是二值退化 |
| **A2（对照轴）** | 同报 `r0_carry_scaled`（R0 选中的**对向**对象承载倍率） | 证明「域内确实存在高承载对象，只是方向不对」——即检索器工作正常 |
| **A3（反证扰动）** | 负例 **`NF1`（参考方位 +180°）**：把对向对象人为变成「同向」 | 若 `NF1` 下 `F_ADQ` **≥ 4 节** ⇒ 证明**判据能够产出 `F_ADQ`**，主路径的 `0/14` 是**真实空缺**而非仪器失效 |

⇒ 三条轴**并列写入硬门**（`G-D2R-6` / `G-D2R-8`）；未通过则 `BLOCKED`。
