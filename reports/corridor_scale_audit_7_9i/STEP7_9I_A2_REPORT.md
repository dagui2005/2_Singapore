## 4. 逐走廊实体核验

### 4.1 KPE 隧道（19 断面，Σobs 230,268 = 靶场总 obs 的 15.2%）

| 指标 | 实测 | 含义 |
|---|---|---|
| `RoadCat` / 匹配边 `highway` | 全 `CATA` / 全 `motorway` | 主车道，非匝道 |
| `selection_tier` / `name_match` | 全 `CATA_T1_DIRECTION_SEMANTIC` / **0.0** | 高置信方向+语义，但**路名全不匹配** |
| 断面长（LTA 几何）中位 | **164.7 m** | 短段，非设施级长链 |
| 反向成对断面 | **4/19**（中点相距 15–74 m、方位差 ≈180°） | 上下行 bore 并存 |
| 匹配边距离中位 | 99.7 m | 匹配边离断面较远 |
| `n_comp>1` / `chain_break>0` / `is_chain` | **18/19** / 12/19 / **仅 1/19** | **绝大多数不是连续有向链** |
| `vc_mean` 中位 / `vc_max` 最大 | **1.718** / **3.569** | **obs 超过容量最大的单条匹配边** |
| `vc_max>1` 断面数 | **16/19** | §4-1 判据成立 |
| 半径设施重建 `F_R/Σobs` | 50 m **0.657** / 100 m **1.439** / 150 m 2.897 | crosswalk 只抓到 0.417 |
| 分类占比（按 Σobs） | **`U_UNIT_MISMATCH` 92.64%** / `P_PARALLEL` 7.36% | 主导机制 |

**判读**：KPE 隧道的 LTA「断面」是一个 **~100–200 m 长的有向短段**，其观测值
（工作日 8 时中位 **12,119 辆/h**，最高 20,342）**超过模型侧任何单条有向 motorway 边的容量**
（中位 6,175、最高 9,500）达 **1.72×–3.57×** —— 这在物理上排除了
「LTA 断面 ↔ 一条有向 MATSim 边」是**同一测量单元**的可能。

同时，crosswalk 在该处**选中了低流量子集**：matched-only `Σ×SCALE` 只有 obs 的 **0.417**，
而**半径 50 m 内的全部 motorway 边**已达 **0.657**、100 m 内 **1.439**。

⇒ 结论：**KPE 隧道的 `norm = 0.117` 不是「缺 8.5 倍流量」，而是「观测单元与仿真对象定义不一致 +
匹配选中低流量子集」。** 该场址**不可用于判定 demand 是否不足**。

### 4.2 ECP（47 断面，Σobs 93,818）

| 指标 | 实测 | 含义 |
|---|---|---|
| `RoadCat` 构成 | `CATA` 63 边 / `SLIP_ROAD` **226 边** | **78% 是匝道/辅路对象** |
| 匹配边 `highway` | `motorway` 63 / **`motorway_link` 226** | 与上一致 |
| `selection_tier` | `CATA_T1_…` 63 / `SLIP_T2_DIRECTION_GEOMETRY` **209** / `SLIP_T1_…` 17 | 匝道多靠**纯几何**匹配 |
| `vc_max>1` 断面数 | **0/47**（`vc_mean` 中位 0.458、`vc_max` 最大 0.724） | **不存在单元冲突** |
| `is_chain` | **30/47** | 多数是连续链 |
| 半径 `F_R/Σobs` | 50 m 1.279 / 100 m 2.580 | |
| 分类占比（按 Σobs） | `C_CHAIN` 49.88% / `P_PARALLEL` 38.37% / `S_SLIP_GEOM` 11.74% | 无 `U_UNIT_MISMATCH` |

**判读**：ECP **没有**观测单元冲突（obs 全部低于单边容量）。它的 `norm=0.132` 完全来自
「`r_sum = 0.810` 再除以 `K_c = 6.149`」。而 `r_med = 0.258` ⇒ **在代表值口径下 ECP 确实偏低（3.9×）**，
但**不是 7.6×**。ECP 的实质问题是 **78% 匹配链落到 `motorway_link`（匝道对象）且多靠纯几何匹配**，
即**「断面 ↔ 边」的对象粒度不一致**。

### 4.3 KPE（3 断面，Σobs 15,362）

`vc_mean` 中位 **0.960**（贴近饱和）、`vc_max>1` **1/3**（担 58.9% obs）、
`is_chain` 2/3、`norm=0.119` vs `r_mixed=0.465`。
样本过小（<30 断面 ⇒ 按项目纪律**不得单独作结论层**），仅作 KPE 隧道与 ECP 之间的过渡证据。

## 5. 口径三选一：`norm` 是否合法

| 口径 | 公式 | 适用前提 | KPE 隧道 | ECP | KPE |
|---|---|---|---|---|---|
| `r_med` | `SCALE·median_e flow_e / obs` | 链（同股车流取代表值） | 0.097 | 0.258 | 0.155 |
| `r_sum` | `SCALE·Σ_{e∈E_c} flow_e / obs` | 平行（不同车流可加） | 0.413 | 0.810 | 0.635 |
| `r_norm` | `r_sum / K_c` | **仅当**全部为链 | 0.117 | 0.132 | 0.119 |
| **`r_mixed`** | 链→`median`，非链→`sum` | **按对象性质逐断面选** | **0.385** | **0.388** | **0.465** |

**实测链占比**：KPE 隧道 **1/19**（⇒ 除以 K **不合法**）、ECP **30/47**、KPE 2/3。

⇒ `norm` 对 KPE 隧道**结构性不适用**（把平行对象当链）；对 ECP 则**过度修正**
（`r_sum` 已含链的重复计数，再除 K 二次惩罚）。
**`r_mixed` 是目前唯一与「逐断面对象性质」一致的口径**；其精化（连续有向链重建）
为下一步 **7.9I-A1**。
