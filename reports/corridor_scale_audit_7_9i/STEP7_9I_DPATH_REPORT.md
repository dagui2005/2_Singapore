## §2 方法（口径见 `PREREG_7_9I_DPATH.md` §2）

### 2.1 上游零流域 `hr(·)`
从链头 `head` 反向 BFS，**只允许经 `flow == 0` 的边**：`hr(head) = 0`；`hr(u) = hr(v)+1` ⟺ 存在 `e: u→v ∧ flow(e)=0`。域规模 **98–5,963 节点**，未触 `CAP_DOM`。

> 为什么只用零流边：本刀问的是「活性流**为什么没有到达**本链」。若允许经活边反向行走，等于假设流已到达，与 `head_in_flow ≡ 0` 矛盾。

### 2.2 最近 upstream active edge `e_near`
`C_in = { e : flow(e) > 0 ∧ to(e) ∈ dom(hr) ∧ hr(to(e)) ≥ 1 }`；
`e_near = argmin ( hr(to(e)), −flow(e), e )`（先最小跳数 → 再最大流量 → 再最小边序）。
⛔ **不按欧氏距离选边**；欧氏最近活边只作 §4.5 诊断披露。

### 2.3 承载链 `A*`（单度活链）
从 `e_near` 沿 `flow > 0` 边双向扩展：向后当尾节点 `n_in_live == 1`，向前当头节点 `n_out_live == 1`；`MAX_STEPS` + visited 防环。

### 2.4 ★流量守恒证据
| 量 | 定义 | 判读 |
|---|---|---|
| `flA_in` / `flA_out` | `A*` 首/末边流量 | — |
| `R_cons` | `flA_out / flA_in` | ≈1 过境守恒；<1 沿链衰减（局部吸收）；>1 沿链生成 |
| `Rn` | `flA_in / fl_in_ext` | 上游分流比（`fl_in_ext` = `A_tail` 活入流之和） |
| `Rd` | `fl_out_ext / flA_out` | 下游续行比；**=0 ⇒ 流量在 `A_head` 终止** |

### 2.5 ★承载充分性（与 D1–D5 **并列**的第二轴）
`carry_scaled = flA_in × SCALE / obs_8_9`（`SCALE = 2.29897`）；`F_ADQ` ⟺ `carry_scaled ≥ CARRY_MIN = 0.50`。
⛔ **基数披露**：这是「单条 MATSim 边流量」对「单 LTA 断面观测」之比，`K_pooled = 5.5434` ⇒ **仅量级参照，不作独立判据**。

### 2.6 分类（互斥，优先级 **D5 > D3 > D2 > D1 > D4**）
`D5`（`C_in = ∅`）→ `D3`（`dn_live > 0`，本链下游同对象有活流）→ `D2`（`dbear ≥ 150°`）→ `D1`（`dbear ≤ 30° ∧ d_own ≤ 60 m`）→ `D4`（其余）。

## §5 判读

### 5.1 对 O1 / D 类裁定的影响

D 类的官方理解（用户 2026-09-30 表述）是：

> **本侧车行道确实存在，也有拓扑入口，但进入这条链的交通流没有形成；它在拓扑上属于「已建但未承载」的零流链。**

### 5.2 两条易混淆命题的分辨（本刀核心目的）

| 命题 | 本刀证据 | 判定 |
|---|---|---|
| **① 车根本没进入这条路（本方向）** | `D2 56.68%`（对向不可供流）＋ `F_LOW 71.02%`（载体流量仅 4.3%–40.7% of 需求）＋ `ms_same_live ≡ 0`（近旁同向对象也是死链） | **★主要方向** |
| **② 车进入了走廊，但被另一条平行/替代有向链承载** | `D1 = 0`（**结构性**，不可检出）＋ `F_ADQ 仅 5 节 28.98%`，且其中**无一是同向紧邻对象** | **仅弱支持**（限于 408–568 m 的同向/斜交对象） |

**★③命名纪律**：D1–D4 一律表述为「**承载对象替代 / 路径重分配**」，⛔ **不得**写作「映射错误 / 建错」。
