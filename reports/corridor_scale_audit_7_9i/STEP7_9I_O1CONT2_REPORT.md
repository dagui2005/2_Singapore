## 2. 方法（口径全部冻结，见 `PREREG_7_9I_O1CONT2.md`）

### 2.1 死管链（同向零流单链）

从 matched 边双向扩展：上游须 `incoming[f(e)]` 中「`flow==0` 的边恰 1 条」，下游须 `outgoing[t(e)]` 中「`flow==0` 的边恰 1 条」。无启发式、确定性。
实测：`dead_chain_len` p50 **13** / p90 **23.8** / max **36**；`upstream_zero_depth = 0` 有 **4** 节、`> 0` 有 **14** 节。

### 2.2 三个「接入」对象

| 对象 | 定义 |
|---|---|
| **链头节点** `head` | matched 边（集合首条）的 `from` 节点 |
| **OSM 接入对象** | `R_ACC=60 m` 内、与链**同向**（`dir<30°`）、`highway ∈ ACCESS_TYPES`（可驾驶；⛔ 排除 footway/cycleway/path/steps/pedestrian/corridor/service/residential/track/construction…） |
| **MATSim 接入对象** | `head` 的**入边数**（拓扑入口） |

### 2.3 ★B 类判据（严格版 = 顶点覆盖率）

对每条「OSM 接入 link way」：沿几何每 `10 m` 重采样顶点 → 每点查 `R_MS2=50 m` 内**同向** MATSim 边 → `cov_frac` = 命中比；`cov_frac ≥ 0.5` ⇒ 已转换。
`conversion_loss` = `OSM_link_n > 0 ∧ 已转换 == 0`。

> **★R1**：原「单点」口径会把**端点落在路口空档**的 way 误判为未转换（49054 的 `479127292` 单点=未转换，覆盖率=**0.893**）⇒ 改覆盖率口径，阈值 `COV_MIN=0.5` 冻结。

### 2.4 细化轴 D / E（预注册即含，非后验补丁）

`ms_same_live` = `head` 的 `R_MS2=50 m` 内、与链同向、且 `flow > 0` 的 MATSim 边数。
- `== 0` ⇒ **D**（本方向在本地无活流）；`> 0` ⇒ **E**（同向活流近在 50 m 内却仍零流）。

### 2.5 `route_accessible`（★预注册即披露为不区分量）

`∃ flow>0 的边 e`，使 `t(e) ⇝ head`（有向可达）。实测 **18/18 = True** ⇒ **不构成区分量**，仅作契约/反例量保留。
