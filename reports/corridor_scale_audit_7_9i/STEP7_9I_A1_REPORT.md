## 2. 方法

### 2.1 口径定义

候选边集 `E` 的每个**弱连通分量** `C`：

| `C` 的形态 | 代表值 `rep(C)` | 容量 |
|---|---|---|
| 有向**路径**（每节点 in/out 度 ≤1 且 边数 = 节点数−1） | `median_{e∈C} flow_e` | `min_{e∈C} cap_e` |
| 非路径（分支/交叉） | `Σ_{e∈C} flow_e` | `Σ_{e∈C} cap_e` |

```
sim_chain = SCALE × Σ_C rep(C)          cap_chain = Σ_C cap_of(C)
r_chain   = sim_chain / obs_8_9         vc_chain  = (sim_chain/SCALE) / cap_chain
```

⇒ 链内**不重复计数**（同股车流只计一次），跨链**可加**（不同车流），
退化时分别回到 canonical median（单路径）与 sum（全平行）。

### 2.2 两级候选池（并报）

| 池 | 定义 |
|---|---|
| **P0** | 冻结 crosswalk 的匹配边集 `E_s` |
| **P1** | `E_s ∪ { e : d(mid_e, mid_s) < 100 m, highway ∈ MAJOR, |Δbear| < 30° }` |

P1 是**重建候选池**（不是交叉表原始候选，后者未落盘），用于回答
「若匹配器当初选到近旁同向对象，断面能否被解释」。

## 5. 判读与下一刀

1. **链重聚合的价值被限定**：它修正了「零流边把 median 拖到 0」的问题
   （如 KPE 隧道 49649：`r_med` 0.000 → `r_chain` 0.270），
   但**在冻结匹配集内无法解释缺口**（pooled 0.119 → 0.188）。
2. **真正的杠杆是候选对象选取**：P1 把 pooled 推到 **0.556**（缺载 1.8×），
   说明 7.9I-A 的「8 倍缺载」中**大部分是匹配对象选取问题**。
3. **但仍剩 72.18% 的 Σobs 判 `C_LOW`** ⇒ 存在**真实的、非尺度的**残余低载，
   量级 ≈ **1.8–5.3×**（取 P1/P0 边界），**远小于** 7.9I-A 的 8.4×。
4. **下一刀 `7.9I-B(b)`**：38 个零流量断面做平行边记账 —— 直接回答
   「MATSim 把流量放到了哪个平行对象上」，并处理 AYE 这类「匹配集全零流」的极端。
