# Step 7.7A 外部数据获取说明 —— 断面级分车型交通量

> **配套**：`STEP7_7A_ENTRANCE_AUDIT.md`
> **状态**：**BLOCKED_ON_EXTERNAL_DATA** —— 本地与开放数据均无此口径；不阻塞主线（7.7B / 7.7C 可并行推进）
> **日期**：2026-09-19

---

## 1. 为什么必须外部获取

本项目空间残差的归因链条目前是：

```
7.6F-1：∂R_spatial/∂f      ≈ 0
7.6G  ：∂R_spatial/∂λ      ≈ 0
7.7A  ：∂R_spatial/∂(车型构成) ≈ 0（R²=0.064，本地代理）
```

三者共同把空间残差**定位**到残余候选：**OD 空间结构 / 观测口径语义 / 网络表征 / 时段实现（temporal）**。

要**严格**排除"观测口径语义（车型占比）"，唯一办法是拿到**观测侧的分车型计数**——
即：某个断面在某个小时的流量中，car / taxi / bus / motorcycle / goods 各占多少。
**这一口径本地不存在，开放数据也不存在**（见审计 §1）。7.7A 的严格版因此必须外求。

## 2. 期望的数据规格（Ideal Spec）

| 维度 | 要求 | 最低可接受 |
|---|---|---|
| **空间** | 与 `TrafficFlow_Links.shp` 的 `LinkID` **可对齐**（1,278 条链路） | 任意断面级点位 + WGS84 坐标，可做 100 m 内近邻匹配 |
| **车型分类** | car / taxi / bus / motorcycle / goods(lorry,van)（≥5 类） | car vs 非-car 二分亦可（足以检验本假设） |
| **时间** | 工作日 **07:00–10:00 逐小时** | 工作日 AM 峰任意时长 |
| **时段匹配** | **2025-11**（与现行观测 `TrafficFlow_Data.json` 同窗） | 2025 ± 1 年，须在论文中声明错配 |
| **颗粒度** | 分车型 **车辆数**（辆/h） | 分车型**份额**（%）亦可（份额 × 现行 `Volume` ⇒ 分车型量） |
| **覆盖** | ≥ 100 断面，且覆盖 EAST / NORTH-EAST / NORTH / radar_in | ≥ 30 断面，含每组 ≥ 3 个 |

**有了它就能做的一件事**（写进方法学）：

```
Q_obs_all(link) = Σ_m Q_obs_m(link)          # m ∈ {car, taxi, bus, moto, goods}
Sim/Obs_car(link) = Sim_car(link) / Q_obs_car(link)
⇒ 若 Sim/Obs_car 的空间格局显著平于 Sim/Obs_all，则空间残差 = 观测口径（车型）伪影，非模型误差
```

## 3. 可能的获取渠道（按可行性排序）

| # | 渠道 | 内容 | 可行性 |
|---|---|---|---|
| **C1** | **LTA 数据申请 / 研究合作**（LTA DataMall 反馈、OneMotoring、LTA 统计处） | 断面级分车型计数（交通调查/自动车辆分类器 AVC 数据） | 最权威；需正式申请，周期不确定 |
| **C2** | **LTA 交通摄像机图像 + CV**（本地已有 90 台 × 8,552 帧） | 点位级车型**构成**（非流量） | 本地可做；但**覆盖与残差错位**（NE 仅 7 台）+ 需 CV 依赖 + 时序错配（2026-05 vs 2025-11） |
| **C3** | **第三方 CV 数据集**（如公开的 LTA 摄像机检测数据集，仅快速路 ~90 机位） | 车型构成（car/moto/bus/truck/van/lorry），快照 ~90 s | 可立即试用；**仅高速路**、为第三方结果，须标注来源与不确定性 |
| **C4** | **LTA 年度统计（Facts & Figures / 年报）** | 全国年度车队构成（car/taxi/bus/motorcycle/goods） | 已有等价物（`data.gov.sg`）；**无空间维度**，只能支撑"全国口径"论证 |

> **建议组合**：**C1 正式申请**（长期、权威）+ **C3 快速试用**（短期、检验方法可行性）。
> ⛔ **不建议**把 C2 作为主路径：其空间覆盖恰好与待解释残差**错位**，会引入新的选择性偏差。

## 4. 若长期拿不到：降级方案（降级但诚实）

1. **承认口径不可分解**（已在 7.6A 记录），把 `Sim/Obs` 的空间残差**标注为「口径混合不可分解」**，
   在论文中明确写成**已知局限**，而不是模型误差（这是当前唯一诚实的写法）
2. 用 **7.7C 的归因矩阵**把残差在「OD 空间结构 / 网络表征 / 时段实现」之间**再分配权重**
3. 以 **`Radial_in` 与 `EAST` 的−30% 缺口**为案例做**机制解释**（如：radial_in 承载大量穿越流与
   非通勤流，而模型只含通勤 car 需求）—— 这属 7.7C 的职责
