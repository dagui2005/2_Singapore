## Status

**零仿真**：只读复用 D01-D04（f = 1.00 / 1.10 / 1.20 / 1.25）的 linkstats；未重跑 MATSim、未改动任何参数、未选定 demand scale。评价接口 = 7.3.6A Final Crosswalk；观测 = 7.1 冻结口径（仅 h7/h8）；λ = 0.075；capacity = 1.00。

## 0. ★ 最关键的先验事实：配置本身允许周期-2 极限环

| 参数 | 值 | 含义 |
|---|---|---|
| `fractionOfIterationsToDisableInnovation` | `Infinity` | **100% 的迭代都在创新**，不存在「停止选路、让网络静下来」的收尾阶段 |
| `strategyName` | `ReRoute`（weight 1.0，唯一策略） | **每个 agent 每一代都重新选路** |
| `learningRate`（planCalcScore） | `1.0` | 计划得分 = 上一代实测值，**无指数平滑** |
| `routingRandomness` | `0.0` | 确定性最短路 —— 上一代贵、这一代就全切走 |

这是产生 **route flip-flop（周期-2 极限环）** 的标准配置组合。因此本步骤**不默认 it.19 已收敛**，而是把「迭代」当成一个显式维度审计。

## 7. 判决

### `UNCONVERGED_PERIOD2_LIMIT_CYCLE__CROSS_F_SIGNAL_BELOW_PHASE_NOISE`

- **收敛性判决 `UNCONVERGED_PERIOD2_LIMIT_CYCLE`**：标定子集的周期-2 振幅最大达 **20.75%**（f=1.20）；全网口径仅 1.40%，放大 14.8 倍。这不是噪声，是结构性的 route flip-flop。
- **可识别性判决 `CROSS_F_SIGNAL_BELOW_PHASE_NOISE`**：单一迭代（it.19）的跨 f 极差 12.86% 小于 f>=1.20 的相位振幅 ~22.3%。
- it.19 的 attainment（归一化 MATCHED 水平 / f，窗口 00-24）：`[1.0, 0.9824, 1.111, 1.0369]`，非单调 = **是**，极差 12.86%。
- 周期均值 attainment：`[1.0, 0.9744, 1.0034, 0.9545]`，非单调 = **是**，极差 4.89%。

### 对既有结论的修正

| 既有结论 | 本步骤修正 |
|---|---|
| 7.4.3「f=1.20 峰 0.8601 -> f=1.25 回落 0.7599」 | **部分是相位伪影**：周期均值把跨 f 极差从 it.19 的 12.86% 压缩到 4.89%；f=1.20 在 it.19 恰好位于其振荡高端，被系统性抬高 |
| 7.4.3-R「残差指向 ReRoute 路径替代」 | **被直接证实**：相位翻转时 MATCHED 的增量被 NON-MATCHED 等量对冲（抵消比接近 1），而全网总量只动 1-2% ⇒ 纯路径替代 |
| 7.4.3-R「约 6.7% 与窗口无关的标定靶场缺口」 | **在周期均值口径下仍存活**，但必须先由相位振幅给出其置信区间；单迭代无法把它与振荡区分开 |

### 由此得到的方法论结论

**在修复 route-choice 机制之前，任何基于单一迭代的 demand scale 判决都不成立。**

## 8. 动作项（按优先级）

1. **★ 最高优先级（配置层，需重跑但代价明确）**：给 replanning 加收尾机制——`fractionOfIterationsToDisableInnovation = 0.5~0.9`；把 `ReRoute` 权重降到 0.10-0.20 并加入 `ChangeExpBeta` / `BestScore`；给 planCalcScore 设 `learningRate < 1`。目标是把标定子集的周期振幅压到 3% 以下，使 Sim/Obs 的单迭代水平具备可辨识性。
2. **零仿真即可立即采用**：评价口径从「it.19 单点」改为**收敛窗 (it.10-19) 的奇偶相位均衡周期均值**；本步骤已证明该口径把跨 f 极差压缩 12.86% -> 4.89%。
3. **不要**在收敛问题解决前再增加 demand scale 的 MATSim 跑次——新增跑次只会扩大同一个相位带。
4. **可并行的数据动作项**（7.6A 已列）：LTA 分车型交通量计数 + HTS 出发时刻，这是把需求口径 f 从区间收敛到单点的唯一途径。
5. 7.6C（OD 空间结构 / 距离带）仍可做，但**必须建立在周期均值口径上**，否则会被同一相位噪声污染。
