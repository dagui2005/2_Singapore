> ⚠️ **重要观察**：5C.1 的 Region×PA 残差随 λ 上升明显（2.32% → 5.76%），而 5B 基本持平（2.3%–2.7%）。
> 机制：AM-v2 阻抗把长距离（跨区）出行惩罚得更重，`exp(−λC)` 在**大 λ** 下更强烈地对抗 Census 的跨区出行结构；块约束与 Subzone 边际之间的"张力"因此被放大，末次 IPF 把块和拉回边际时产生的块偏差也随之增大。
> 残差集中在少数几个块（低 λ 时集中于 PUNGGOL；高 λ 时集中于 BUKIT PANJANG / BOON LAY / PASIR RIS 等），**绝对量级 ≤ 1,148 次 / 1,935,235 ≈ 0.06%**，属数据内在不一致（见 README §4.4 的 2.2% 硬地板）。
> **含义**：若希望 Census 结构尽量贴合，λ 应偏 **0.05–0.10**；高 λ（0.125/0.15）以牺牲 Region×PA 贴合换取更强的距离衰减。**这一步不据此冻结 λ**。

### 5.3 结论解读

1. **换用 AM-v2 阻抗后，OD 反而略偏"本地化"**：区内份额系统性上升（如 λ=0.10：1.15%→1.47%，+27%），跨区份额与 >30min 长距离份额小幅下降。原因：AM 阻抗对长距离出行惩罚更重，`exp(−λC)` 把质量更多地压回近距离对。
2. **因此"平均通勤时长"并未机械变长**：在同一口径（@AM）下，5C.1 的平均时长比 5B **低** 0.2–0.6 min（λ=0.10：17.90→17.53）。阻抗层变长 ≠ Prior OD 的平均时长变长。
3. **Census `Region×PA` 结构对阻抗选择几乎不敏感**（它是被强加的）：两套 OD 的块份额 L1 变化仅 0.10%（λ=0.05）→ 0.46%（λ=0.10）→ 2.21%（λ=0.15）；单块最大变化 ≤ 0.23 个百分点。
4. **λ 的选择比阻抗的选择影响更大**：5B↔5C.1 的总变差距离随 λ 从 2.3% 升到 6.7%，说明"距离衰减强度"是更主导的结构杠杆。
5. 变化最大的块（λ=0.10）：CENTRAL→DOWNTOWN CORE (+0.042pp)、CENTRAL→QUEENSTOWN (+0.035pp)、CENTRAL→BUKIT MERAH (+0.035pp)、NORTH→WOODLANDS (+0.027pp)。
