# Step 7.5A — S100c 预注册判据（跑前固定）

**登记对象**：S100c (N=100,000, f_cap=0.50) vs S200 (N=200,000, f_cap=1.00)

**目的**：S100c 不是「继续调容量」，而是**验证 100k 样本在等效供需比下能否复现 200k 的交通状态** —— 决定后续计算规模的关键实验。

**定义**：`f_cap=0.50 = N_sample/N_ref`（100k/200k）仅作**采样一致性校正**，保持同一物理供需比；**不是**交通供给标定参数（与 Phase 1 的 `capacity_factor` 严格区分）。

## 判据表（预注册）

| ID | 判据 | 目标 | 门槛 |
|---|---|---|---|
| C1 | 动力学等价性：raw flow ratio 中位数 | 接近 0.50（|中位 − 0.50| ≤ 0.05） | **硬门槛** |
| C2 | 扩样后等价性：scaled S100c/S200 比值中位数 | 接近 1.00（|中位 − 1| ≤ 0.10） | **硬门槛** |
| C3 | scaled ratio 在 ±10% 内的断面占比 | 尽可能高（报告值，不作为门槛） | —（仅报告） |
| C4 | scaled ratio 在 ±20% 内的断面占比 | ≥ 0.80（较强证据） | **硬门槛** |
| C5 | Pearson / Spearman（scaled sim 逐断面 vs S200） | Pearson ≥ 0.90 且 Spearman ≥ 0.95 | **硬门槛** |
| C6 | 结构保持：CATA/SLIP 相对 S200 的系统性漂移 | |Δ(CATA/SLIP) vs S200| ≤ 0.05（主窗口 08-09） | **硬门槛** |
| C7 | 三窗口方向一致 | 07-08 / 08-09 / AM：|Δ(CATA/SLIP)| 均 ≤ 0.05 且三窗口偏差同号 | **硬门槛** |

**通过规则**：全部硬门槛（C1/C2/C4/C5/C6/C7）PASS → 判定 100k 在等效供需比下可替代 200k；C3 仅报告。

## 阈值依据

- **C1**：S100（f_cap=1.00）实测 0.6174（+0.1174）明确越界 → 作为反例基线
- **C2**：与既有 decide() 容差一致
- **C3**：用户判据表：±10% 仅要求'尽可能高'
- **C4**：用户判据表明确 ≥80%
- **C5**：S100 已达 0.9006 / 0.9567（形态一致性本就很高）→ 作为保持线
- **C6**：Phase 2 λ 极差 0.0146（λ 不动）、Phase 1 capacity 极差 0.2371 → 取 0.05（≈capacity 极差 1/5）为'明显漂移'界线
- **C7**：用户判据表：三窗口方向基本一致

## 跑完要回答的三个问题

1. **动力学等价性**：S100c 与 S200 的 raw flow ratio 是否稳定在 0.50 附近（而非 S100 的 0.6174）。
2. **扩样后等价性**：`S100c×4.59794` vs `S200×2.29897` → 逐断面比值、WMAPE、GEH、Pearson/Spearman。
3. **结构是否保持**：`CATA/SLIP` 与三时间窗 07–08 / 08–09 / AM 是否同时稳定。

## 固定项（跑 S100c 时不变）

`N=100,000` / `f_cap=0.50` / `λ=0.075` / 20 iterations / `seed=4711` / `routingRandomness=0` / same network / same OD / same departure profile / same Final Crosswalk / same evaluation target。
