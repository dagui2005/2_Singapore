## 4. 联合目标（预注册判据）

两把尺子，同一次评分：

- **F_flow** = `Sim/Obs(cycle it.10–19)`（冻结口径，复用 `audit_sampling_capacity_7_9a1.guardrail_eval`）。
- **F_speed** = SpeedBand 拟合（主域 08–09 有流链）：`bias / MAE / RMSE / Pearson r / band 精确·±1·band bias`。

**判据**
- **改善** ⟺ `ΔRMSE_speed < 0` **且** `F_flow ∈ [0.95, 1.05]`（不牺牲流量对账）。
- **负例否决** ⟺ `SB-A3n` 与 `SB-A3` **同等改善** ⇒ 判为「**非空间效应**」，A3 的改善作废。
- **显著性** ⟺ 相对基线 `|ΔRMSE| ≥ 0.5 km/h`（预注册阈值，避免噪声）。
- **上界解释** ⟺ A4 的改善若远大于 A1/A3 ⇒ 说明差距主要是**速度水平**而非拥堵机制。

## 6. ★可行性预筛（零仿真，已算出）

在 91,956 条匹配链（2,812.1 km）上：

| 量 | 值 |
|---|---|
| `v/c` 中位 / 均值 | **0.0063 / 0.0457** |
| `v/c ≥ 1` 占比 | **0.00%** |
| **A3 可饱和（可被削到减速）** | **4,838 链 / 236.5 km（5.3%）** |
| **A3 不可行（需求过低，削容量也无法饱和）** | **87,100 链 / 2,574.9 km（94.7%）** |
| A4 将改变 | 91,956 链（100%） |

**先验结论（预注册，不得事后追认）**：
> 仿真需求远低于容量（v/c 中位 0.006），**94.7% 的观测网络在容量侧"物理上无法被减速"**。
> ⇒ **A3（定向容量）最多只能影响 5.3% 的观测里程**，预期改善有限；
> ⇒ 瓶颈大概率在**自由流速度水平**（A4）或**拥堵机制**（A1/A2），而非流量-容量比。
