## 0. 先固定一个数学事实（本审计的出发点）

当前所有臂共用同一扩展系数：

\[
R_i=\frac{SCALE\cdot\sum_g Q^{sim}_{g,i}}{\sum_g Q^{obs}_g}
\]

观测域、断面聚合方法（`median(匹配有向边 HRS8-9avg)`）、分母、`SCALE` 三臂完全相同 ⇒

\[
\frac{R_{\mathrm{A5}}}{R_{\mathrm{v1.0}}}=\frac{\sum_g Q^{sim}_{g,\mathrm{A5}}}{\sum_g Q^{sim}_{g,\mathrm{v1.0}}}
\]

**⇒ 固定 `SCALE` 本身不能解释两臂之间的比例变化**（它等比例放大两臂）。本审计要回答的是：
**网络自由流速度改变后，仿真实际产生的路段流量为什么变了。**

> `SCALE=2.29897` 的绝对值是否合理 = **独立问题**，可另案审计；⛔ **不得**把本次约 6 个百分点归因于 `SCALE`。

`SB-A5ind` 只换了 OD 构建（零 SpeedBand），网络 `freespeed` 与 `SB-A5` 相同 ⇒ 两臂差异属**需求侧**；`SB-A5` vs v1.0 差异属**供给速度侧**。

## 2. 三类原因（三分支）

| 分支 | 要回答的问题 | 核心证据 |
|---|---|---|
| **A. 时间窗内的流量转移** | 流量是否从 08–09 移到了其它小时，导致只看一小时的比例上升？ | 各臂逐小时 `HRSx-yavg`（it.10–19 周期均值，构造**全时段** cycle 文件）；07–08 / 08–09 / 09–10 / 10–11 …；**可观测双小时 07–09 累计**与时段占比 |
| **B. 路径重分配** | 改 `freespeed` 后车辆是否改走更多/不同的观测路段？ | 逐 LTA 断面 ΔQ；正/负变化**抵消结构**；按道路等级 / 区域 / 环线 / 轴向 / CBD 距离的**集中度**；**全网 vs 匹配子集**对照（覆盖率陷阱） |
| **C. 观测域与聚合口径** | 整体比例是否对断面匹配、`median/mean/positive-median` 等聚合高度敏感？ | 固定同一批 576 断面，重算多种聚合；报告匹配覆盖、`n_zero_sim`、`n_links` 分层 |

**⚠️ 预注册警告（用户裁定）**：LTA TrafficFlow **只有 07–08 与 08–09 两小时**。若仿真显示大量流量"转到 09–10"，**不能仅凭仿真数据就认定总量更合理** —— 这只证明**时间窗敏感性**，仍需对应时段实测数据验证。⛔ 09–10 及以后只作**敏感性**陈述，不作结论。

## 3. 审计输出（三张表 + 两张辅助）

### 表 2 `esb03_section_delta.csv` —— 逐断面差异（576 行）
每条 LTA 观测路段：
\[
\Delta Q_g=Q^{sim}_{g,\mathrm{A5}}-Q^{sim}_{g,\mathrm{v1.0}},\qquad \Delta Q'_g=Q^{sim}_{g,\mathrm{A5ind}}-Q^{sim}_{g,\mathrm{A5}}
\]
识别增/减路段、各自贡献、正负抵消净额，并按**道路等级 / 区域 / 环线 / 轴向 / CBD 距离 / 匹配边数**分组。
辅助：`esb03_concentration_by_group.csv`（分组集中度）、`esb03_network_vs_matched.csv`（全网 vs 匹配子集）。

### 表 3 `esb03_window_sensitivity.csv` + `esb03_aggregation_sensitivity.csv`
- **3a 时间窗**：逐小时 Σsim（三臂 + Δ vs v1.0），区分「单小时变化」「可观测双小时变化」「不可观测小时（仅敏感性）」。
- **3b 聚合**：同一批 576 断面下 `median / mean / positive_median / max` × 三臂，报 `Sim/Obs` 与 **`R_A5/R_v1.0`（比值对聚合的敏感性）**；匹配集敏感：全 576 / 三臂皆 sim>0 / `n_links==1` / `n_links>1`。

## 5. 必须随结论声明的限制

- **Level 1（本审计可做）**：只读分离"全网 / 观测域 / 时间窗 / 聚合"四层贡献；**不做因果断言**。
- **Level 2（须补数据）**：`TrafficFlow`(2025-11) 与 `SpeedBand`(2026-05) 不同期；obs 仅 07–08/08–09 ⇒ 09:00 以后**无实测**，时间窗分支**无法闭环**。
- **物理**：`freespeed` 变更改变的是**路段时间成本**；若产生拥堵，linkstats 的 `HRSx-yavg`（入流量）会随**排队/滞留**变化 —— 这是待检验的机制，⛔ 不得先验认定。
