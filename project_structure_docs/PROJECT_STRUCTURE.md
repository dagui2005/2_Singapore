## 项目概述

本项目是一个完整的新加坡交通数据下载、处理和分析工具集，主要功能包括：

1. **LTA DataMall API数据下载** - 支持30个API的历史和实时数据
2. **静态数据管理** - 人口、交通、公共交通等静态数据集
3. **OSM数据解析** - OpenStreetMap数据的解析和处理
4. **可行性评估** - 交通数字孪生可行性评估
